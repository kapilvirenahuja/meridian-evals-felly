How We Chose the Architecture

8 decisions that shaped Felly Club's technical design. Each one traces back to a profile dimension, an LTM recommendation, a budget constraint, or a decision you made during planning.

The one-line story

A TypeScript modular monolith (NestJS) on AWS managed services (ECS Fargate, RDS, ElastiCache, OpenSearch) with dual Stripe accounts (India + Global), KeyCloak for identity, BullMQ for async work, and GDPR per-session consent for recordings. Web-only MVP on Next.js / Vercel. No microservices, no Kubernetes, no mobile — built for a EUR125K / 16-week delivery.
